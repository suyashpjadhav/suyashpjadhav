## Research & Freelance Work

**AgriAid: multimodal crop advisory pipeline** (Research Intern, BIT Mesra)
- Modular pipeline routing crop inputs through 2 independent branches into one advisory output
- Fine-tuned **EfficientNetB0** for 7-class potato leaf disease detection, raising test accuracy from **69.94% to 86.06%** with W&B tuning
- Built a 3-stage rice Brown Spot severity pipeline (HSV segmentation, SAM lesion detection, IRRI-standard grading) validated on 350 images

**RAG Course & Curriculum Generator** (Freelance AI Engineer)
- RAG pipeline with LangChain LCEL over PDF, PPTX and article sources, using a custom cosine-similarity chunker
- Compiled **DSPy** pipeline (BootstrapFewShot) for hallucination-resistant, rigidly structured output
- 2-backend vector store (ChromaDB + Pinecone) with a hash/version manifest for idempotent indexing
